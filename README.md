# Basic Chatbot Using Python

## Project Description
This is a simple rule-based chatbot developed using Python as part of the CodeAlpha Python Internship.

The chatbot interacts with users and provides predefined responses based on their input.

## Features
- Responds to greetings.
- Answers "How are you?"
- Says goodbye when the user exits.
- Handles unknown inputs with a default response.

## Technologies Used
- Python

## Concepts Used
- Functions
- While Loop
- If-Else Statements
- User Input and Output
- String Methods

## How to Run
1. Download the `chatbot.py` file.
2. Open it using Python.
3. Run the program.
4. Enter messages and interact with the chatbot.

## Sample Inputs and Outputs

| User Input | Chatbot Response |
|---|---|
| hello | Hi! |
| how are you | I'm fine, thanks! |
| bye | Goodbye! |
